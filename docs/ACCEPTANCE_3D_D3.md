## 二、主批次统一验收（**2026-10-25 用户回报 T1~T10 全部通过**）

### 交付

- **单位模型 25 个**（每个都有 Idle / Walk / Attack / Death）：
  - 可玩池 21 个：女主、兔射手、鼹鼠火枪手、火精灵、雷精灵、飞斧汪、双斧火钳、小小、蟑螂、蟑螂恶霸、猫炮手、猪猪配香菇、火又鸟、幺蛾子、马蜂王、鸦王、岩石史莱姆、锤锤莱姆、棒槌史莱姆、瓜牛炮、蝴蝶仙子。
  - 热门锁定 4 个（无原画，按卡通风格自行设计）：小乌鸦、大块头（棕熊穿背带裤）、小骷髅、龙宝宝。
  - 小小原有的 3 段动作不变，补了 Death（石身侧倒、手臂软塌、嫩芽低垂）。
- **派生 3 个**（复用父模型，体型按配置）：火又鸟·重生、幼蛾子、小岩史莱姆。
- **借用 11 个**（锁定且无原画的单位，借外形最接近的池内模型 + 整体色偏，便于和本尊区分）：
  - 小蝙蝠 = 小乌鸦（紫）；冰精灵 = 雷精灵（冰蓝）；见习骑士 = 飞斧汪（浅色）；洞穴蜘蛛 = 蟑螂（暗紫）；
  - 骨头撞车 = 猪猪配香菇（骨白）；攻城槌 = 猪猪配香菇（木色）；火法师 = 蝴蝶仙子（橙红）；回旋斧手 = 双斧火钳（橙）；
  - 雷法师 = 蝴蝶仙子（亮黄）；熔岩龙 = 龙宝宝（红）；喷火小龙 = 龙宝宝（橙）。
  - 只改表现层映射（`view/three_d/unit_models.gd`），不动配置；以后有原画再做专属模型。
- **结果**：units.json 的全部 39 个单位都有 3D 模型，战场上不再出现「代理」胶囊。
- **地形**：草地（1 格棋盘双色）、流水河道（波纹 + 两岸泡沫）、石砌河岸、木桥（Blender 模型）、场地石沿、一圈木栅栏，场外点缀树 / 灌木 / 石块（左右对称）。栅栏和点缀合批绘制（MultiMesh）。
- **光照**：太阳 0.7 + 环境 0.3 + 补光 0.12。浅色石头、米色、草地都不再过曝。
- **满场预算**：最坏情况是 30 个最重单位（幺蛾子 4,610 三角面）+ 6 塔 + 全部地形，共 **22.7 万三角面**，在 26 万预算内。每个单位 1 个材质，描边多一个 pass。
- **生成管线**：`tools/blender/`，每个资产一份脚本，可重跑。全部 32 个生成资产已用后台方式重新构建一遍，入库文件可复现。直播模式（`live_build.py`）只用于在 Blender 里展示建模过程。

### 打开方式

- **战斗预览**：`res://view/labs/battle_3d_preview.tscn`，按 F6。按 T 观战，或自己拖卡出兵。

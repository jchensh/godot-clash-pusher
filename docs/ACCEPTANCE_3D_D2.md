## 交付范围

- 3D 出牌输入 `view/three_d/deploy_input_3d.gd`：屏幕点 → 正交相机射线 → 地平面 → tile；落点抬到手指上方 1.6 格（与 2D 同值）。
- 合法性与 2D 同口径：兵牌走 `Arena.can_deploy`（己方半场 + 可走地面，河/桥/塔脚/敌方半场都不行），法术场内任意点；场外、松手在顶栏或手牌栏都算取消。
- 拖拽 ghost：落点环、兵位圆盘（按卡牌数量，例：蟑螂小队 3 个）、己方半场脉动高亮；AOE 法术显示配置半径的范围圈，直伤法术显示准星；合法绿、非法红。
- 合法松手只发 `deploy_requested(手牌格, tile)`，由调用方走既有权威入口：PvE 用 `Player.try_play_card`，PvP 将在 D5 改为发 DeployCmd。3D 层不自建出牌通道。
- 镜头 `view/three_d/battle_camera.gd`：竖屏 750×1334 下 55° 俯角正交，场地撑满宽度、居中在顶栏与手牌栏之间，我左敌右；side2 翻转后本方仍在左。
- 预览升级为真人操作：你拖卡打本方，AI 打对方；T 键切回 D1 那种双 AI 观战。

## 打开方式

Godot 编辑器打开 `res://view/labs/battle_3d_preview.tscn` 后按 F6。本地对局，不联网、不写经济/进度。
按键：拖卡出兵，右键取消拖拽，空格暂停，R 重开，F 翻转视角，T 观战（双 AI），1/2/3 切 1/2/4 倍速。

## 已知限制（不算不通过）

- 手牌栏是预览专用的简易按钮，没有卡面图；正式战斗 HUD 随 D4 接线时复用现有卡牌组件。
- 法术和投射物仍无 3D 特效（D8）；除小小外的单位、塔、废墟仍是几何代理（D3）。
- 场地宽度受竖屏限制，上下各有一段空白；正式 HUD 接入时再按实际顶栏/手牌栏高度微调。

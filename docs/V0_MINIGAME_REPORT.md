## 2. 降到 Godot 4.5.2 的实测

- 方法：在工作区里用官方 Godot 4.5.2 完整导入项目（工作区原先没有 `.godot` 缓存）。工作区已经复制了 master 上未提交的 D8b 改动。
- 结果：
  - 导入：0 个错误。首次导入时有一条字体「加载失败」，是导入顺序造成的，第二遍导入为 0。
  - 客户端单测 **514/514**，SCRIPT ERROR 为 0。
  - 冒烟全部通过：战斗页、联机页、D1~D3 预览、特效、画质三档、王国、菜单、图鉴展示台、小小展示台。
  - 性能（30 单位，3D 倍率 × 1.44，p95）：

| 指标 | 4.5.2 | 4.6.3 |
|---|---|---|
| 高档 draw call | 424 | 459 |
| 低档 draw call（含 2D） | 214 | 216 |
| 低档 draw call（仅 3D） | 147 | 131 |
| 低档三角面 | 20.3 万 | 19.8 万 |

  - 网格 LOD 和 3D 渲染倍率在 4.5 的 Compatibility 渲染器下同样有效；画面截图和 4.6.3 一致。
- 正式降级时要做的事（都很小）：
  - `project.godot` 里的 `config/features` 从 4.6 改为 4.5；
  - 主菜单场景里有一个 4.6 写入的节点编号，4.5 能读，不用改；
  - 编辑器插件 godot-ai 在 4.5 无界面模式下加载无报错（编辑器界面里还没实测）；
  - 全员换用同一个 4.5.x 编辑器。
- 还需要确认：抖音模板是 4.5.1，我们的编辑器是 4.5.2，打出的资源包和 4.5.1 引擎能否完全对上，要在开发者工具里跑一次才能确认。保险做法是编辑器也用 4.5.1。

## 3. 抖音官方插件导出与包体

- 插件：`douyin_godot_sdk_1.0.4`，放在 `addons/ttsdk` 和 `addons/ttsdk.editor`。编辑器侧是一个 GDExtension，要求 4.5 以上。导出时会联网拉取抖音的配置和对应版本的引擎模板。
- 工作区改动：
  - 启用插件；
  - 加 `tt` 自动加载；
  - 打开 ETC2/ASTC 纹理压缩（插件强制要求）；
  - 新建 `export_presets.cfg`，导出平台为 `tt-minigame`，AppID 先填占位值。
- 导出目录：`F:\godotTowerPush\v0-tt-build`（debug）、`v0-tt-build-release`、`v0-tt-build-slim`（去掉音乐和开发插件）。
  - 生成的文件：`game.js`、`game.json`、`project.config.json`、`godot.config.js`、`godot/`（引擎 + 资源包）。
  - `project.config.json` 里的 `urlCheck` 是 false，说明开发阶段不校验域名。
- 引擎大小：debug 8.4 MB，release 6.5 MB（brotli）。主包上限是 4 MB，所以**引擎必须放分包**，插件自带分包导出选项。
- 资源包组成（48.0 MB，1276 个文件）：

| 内容 | 大小 | 说明 |
|---|---|---|
| 音乐（mp3） | 26.9 MB | 4 首 BGM，最大一首 12.4 MB |
| 贴图 | 11.8 MB | 大头是旧 2D 战场图、旧序列帧，D9 本来就要清理 |
| 字体 | 3.7 MB | 像素中文字体 2.5 MB + 站酷快乐体 1.2 MB |
| 3D 模型（含王国） | 3.4 MB | |
| 代码与配置 | 约 1 MB | |
| 开发插件 godot-ai | 1.1 MB | 正式包要排除 |

- 去掉音乐和开发插件后，资源包为 20.2 MB。再加上：
  - D9 清旧 2D 素材，约 -8 MB；
  - 字体只保留用到的字，约 -3 MB；
  - release 引擎 6.5 MB；

  估计总包 **13~15 MB，可以进 20 MB**。音乐走 CDN 或降码率。这样首个版本可以先不做通用资源下载系统，只把音乐放 CDN；KAN-149 的完整 CDN 方案可以按内容增长再上。
- 发现的问题：导出目录里同时有 `main.pck` 和压缩后的 `main.br`，体积重复一份。需要确认开发者工具上传时是否只带 `main.br`，否则要在打包流程里删掉 `main.pck`。

   - 低档就是小游戏的默认档。
   - 如果包体超限导致无法预览，就先出一个瘦身包验证。

## 2. 降到 Godot 4.5.2 的实测

- 方法：在工作区里用官方 Godot 4.5.2 完整导入项目（工作区原先没有 `.godot` 缓存）。工作区已经复制了 master 上未提交的 D8b 改动。
- 结果：
  - 导入：0 个错误。首次导入时有一条字体「加载失败」，是导入顺序造成的，第二遍导入为 0。
  - 客户端单测 **514/514**，SCRIPT ERROR 为 0。
  - 冒烟全部通过：战斗页、联机页、D1~D3 预览、特效、画质三档、王国、菜单、图鉴展示台、小小展示台。
  - 性能（30 单位，3D 倍率 × 1.44，p95）：

| 指标 | 4.5.2 | 4.6.3 |
|---|---|---|
| 高档 draw call | 424 | 459 |
| 低档 draw call（含 2D） | 214 | 216 |
| 低档 draw call（仅 3D） | 147 | 131 |
| 低档三角面 | 20.3 万 | 19.8 万 |

  - 网格 LOD 和 3D 渲染倍率在 4.5 的 Compatibility 渲染器下同样有效；画面截图和 4.6.3 一致。
- 正式降级时要做的事（都很小）：
  - `project.godot` 里的 `config/features` 从 4.6 改为 4.5；
  - 主菜单场景里有一个 4.6 写入的节点编号，4.5 能读，不用改；
  - 编辑器插件 godot-ai 在 4.5 无界面模式下加载无报错（编辑器界面里还没实测）；
  - 全员换用同一个 4.5.x 编辑器。
- 还需要确认：抖音模板是 4.5.1，我们的编辑器是 4.5.2，打出的资源包和 4.5.1 引擎能否完全对上，要在开发者工具里跑一次才能确认。保险做法是编辑器也用 4.5.1。

### 5.2 踩过的坑（按出现顺序）

1. **抖音 4.5.1 的 debug 引擎模板是坏的**：开发者工具报 `WebAssembly.instantiate(): Compiling function #421 failed`。抖音当前下发的 8 个模板（web / web_trim / web_2d / web_2d_trim × debug / release）md5 与官方一致，用 Node 24 逐个编译：4 个 debug 全失败、4 个 release 全通过。→ 一律用 release 导出（插件的 `--export-release`）。值得反馈抖音。
2. **导出用的编辑器版本**：已改用官方 Godot 4.5.1（`F:\godotTowerPush\_tools\godot-4.5.1`，SHA512 校验通过），与抖音模板同版本；4.5.1 下单测 518/518。
3. **输入框看不见字**：master 原有 bug，白字白底，已在 master 修。
4. **输入的字传不到游戏**：抖音适配层对默认键盘类型的输入框只在键盘「完成」时把文字交给引擎，开发者工具里「完成」常不触发 → 引擎一直以为名字为空 → 「进入」按钮禁用、点了没反应。→ 网页导出下输入框改 `KEYBOARD_TYPE_URL`（适配层逐字同步），「进入」按钮不因空名禁用；登录页与 HTTP 层加 `[MG]` 诊断日志。
5. **只允许 https / wss**：`http://localhost` 直接被拒（`url support protocol is [https]`），勾「不校验合法域名」也不行。→ 分支 `config/network.json` 改连正式服。
6. **开发者工具的代理坑**：勾了「不校验」后报 `request:fail protocol mismatch`。开发者工具内部的 axios + follow-redirects 读用户级环境变量 `HTTP_PROXY/HTTPS_PROXY=http://127.0.0.1:7897`，http 代理配 https 目标触发断言；Clash 规则管不到。→ 用 `F:\godotTowerPush\_tools\start_douyin_devtools_noproxy.bat` 启动（清代理变量 + `NO_PROXY=jeffgame.tech`），**启动前要彻底退出旧实例**。另：「不校验合法域名」按项目目录存在 `project.config.json` 的 `urlCheck`，换导出目录要重新勾。
7. **包体超限**：先报总包 51 MB > 30 MB，瘦到 25 MB 后又报「源码包 > 20 MB」。抖音规则 = 主包 ≤4 MB、主包 + 分包 ≤20 MB（CDN 远程资源不计）。→ 去掉 BGM（26 MB，AudioManager 缺资源会静默跳过）、开发插件 godot-ai、未引用的像素字体 / 旧 2D 王国图 / 旧战斗背景；58 张大于 40 KB 的贴图改有损 WebP（0.85）；开分包 `douyin/subpackage_on=true`。贴图 11.8 → 4.1 MB，总包 51 → **15.6 MB**。
8. **两端互顶**：真机调试时模拟器也在用同一账号，服务器「一号一会话」互相踢、每 2 秒重连循环。不是网络问题，测试时只开一端或用不同账号。
9. **战斗中请求黑洞**：开战后手机的 HTTP 请求一条都没到服务器（Caddy 访问日志为证），会话 wss 却一直在线。Caddy 默认回 `Alt-Svc: h3`，抖音的网络库改走 HTTP/3（UDP 443），跨境 UDP 被丢。→ 正式服关 HTTP/3、不再发布 443/udp（release `1741de2`，已发布，只重建 Caddy）。
10. **token 进了访问日志**：抖音安卓 WebView 把含 token 的完整 wss 地址填进 `Origin` 头，Caddy 只脱敏了 query。→ 日志过滤删 `Origin` 头（同 `1741de2`）。

### 5.3 上线还差什么

- **服务器与备案**：抖音合法域名必须 HTTPS、不能 IP / 端口、必须 ICP 备案；开发者工具和手机调试模式可勾选跳过，测试版 / 正式版不行。正式服在 GCP 台湾，域名无法备案 → 需要境内云服务器 + 中国大陆主体备案的域名，再加小游戏备案。
- **抖音登录**：用 `tt.login` 拿 code，服务器用 AppSecret 换 openid 绑定账号（AppSecret 只放服务器）。
- **背景音乐**：压码率或改 CDN 下载。
- **被顶号不再自动重连**（master 同样存在的问题）。
- 微信小游戏：未开始。

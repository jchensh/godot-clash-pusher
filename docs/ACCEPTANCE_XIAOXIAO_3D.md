- 源文件：`assets/models/xiaoxiao/source/xiaoxiao_animated.blend`；该目录的 `.gdignore` 避免引擎重复自动导入 Blender 源文件。

## 动作

| Godot 动画 | 播放方式 | 预期 |
|---|---|---|
| Idle | 循环，约 2.03 秒 | 身体轻微起伏，手臂放松，嫩芽摆动 |
| Walk | 原地循环，约 1.37 秒 | 交替迈步和摆臂，身体有重量感；支撑脚贴地 |
| Attack | 单次，约 1.53 秒 | 后撤蓄力、出拳、收势，结束回 Idle |

Blender action 保留 `Idle_loop` / `Walk_loop` 后缀；Godot 导入自动识别循环并移除命名后缀。
行走逐帧补偿脚底高度；不带 root motion。速度控制是表现预览，不改变游戏逻辑 tick。

## 真人验收（待执行）

在此 worktree 的 Godot 工程打开 `view/labs/xiaoxiao_showcase.tscn`，按 **F6**。
也可运行：`godot --path . res://view/labs/xiaoxiao_showcase.tscn`。

| 用例 | 操作 | 通过标准 |
|---|---|---|
| A1 默认 | 启动后观察 10 秒 | 小小有灰石/绿苔/黑眼睛；默认待机持续，UI 可读，无报错 |
| A2 行走 | 点“行走”或按 2，观察多个循环 | 双腿交替，拳头摆动，嫩芽跟随；无突跳、明显穿地或漂浮 |
| A3 攻击 | 点“攻击”或按 3 | 能看清蓄力→出拳→收势，结束自动切待机 |
| A4 暂停 | 行走时点暂停，等两秒，再点继续 | 暂停时角色姿态保持；继续后恢复动作 |
| A5 速度 | 将速度拖到 0.25×、2× | 动作相应变慢/变快；暂停续播仍正常 |
| A6 观察 | 拖动空白区域/滚轮，点击自动旋转与重置视角 | 可看到侧背面；缩放有上下限；重置回初始角度 |
| A7 尺寸 | 调整窗口大小 | 模型不被横向切掉，动作按钮可用 |

键盘：1 待机、2 行走、3 攻击、空格暂停/继续、R 重置视角。

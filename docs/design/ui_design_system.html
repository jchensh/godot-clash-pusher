规则

  • 阵营色只看「我/敌」，不看 side：本方恒蓝、敌方恒红，塔、血条、HUD 一致。
  • HUD 底板 (0.93,0.97,1.0,0.96)，上沿 2px 描边 (0.66,0.83,0.93)。
  • 手牌底 = stone 面色；选中卡 = 暖黄 (1.0,0.87,0.45) 并上浮。
  • 拖拽落点：绿圈合法、红圈非法，半透明填充同色。
  • 圣水 10 格，紫色；费用角标用同一紫色。

审计

与系统不一致的地方

提取时发现的残留，按影响排序。两条高优先级已于 2026-10-24 修复（merge 3d6a018），其余待排期。

已修

三个场景夜色深底 · 弹窗暗幕夜色紫黑

deck_builder、campaign_scene、run_scene 换成上方状态底色；modal.gd 暗幕改 COL_DIM @ 0.5；领奖宝箱与 run 覆盖层垫白卡。单测守门：已迁移文件禁夜色字面量。

中

其余夜色残留

kingdom_building_modal.gd:34 面板深紫底、main_menu.gd 两处标签底、kingdom.gd 三处自绘标签底、hud_widget.gd 锁罩。

中

当前关卡行底色是深棕

stage_map.gd:19 ROW_CURRENT_BG = #96701e，深棕底配深字对比不够。建议改淡暖黄 #fff8e1，描边沿用 accent（上方样张已按此画）。

中

常量名与颜色对不上

COL_GOLD 实际是天空蓝，COL_PARCHMENT 是深青蓝；COL_CROWN 注释说「= PixelUI COL_GOLD」，两者早已不同色。新来的人按名字取色会取错。

中

战斗常量复制了两份

battle_scene.gd:28-59 与 net_battle_scene.gd:35-46 各维护一套阵营/圣水/卡面色，圣水色在 hud_widgets.gd:151 还有第三份。

低

字号散成 30 多级

从 10 到 96 都有，最常用的是 22 / 24 / 26 / 18。按上方 7 级阶梯收拢即可；按钮默认 34 实际几乎没人用，多数传 22–30。

低

设计坐标两套

project.godot 画布 750×1334，但 modal.gd 与 toast 按 720×1280 换算。目前不出错，后续新组件容易照抄出偏差。
